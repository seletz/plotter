# About

This is the public logbook for plotter designs I make on my **iDraw H A1** pen plotter.

## Authoring rules

Pages here are **hand-written**. AI assistance is limited to:

- spell-check
- light grammar fixes

No AI-generated prose, no AI-generated descriptions of the work. The logbook voice is
mine.

## Tech stack

- **Site generator:** [Zensical](https://zensical.org/) (markdown-based)
- **Hosting:** GitHub Pages
- **Deployment:** GitHub Actions on push to `develop`
- **Tooling:** [`mise`](https://mise.jdx.dev/) for tasks, [`uv`](https://docs.astral.sh/uv/)
  for Python package management.

## Source

The site source lives at [github.com/seletz/plotter](https://github.com/seletz/plotter).
