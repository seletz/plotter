# Plotter Logbook

This is a public logbook of designs I make for my pen plotter (an **iDraw H A1**).
Each design gets its own page, multiple designs are in flight at the same time, and
the site is hand-written.

The point of this site is the **paper output** — not the code, not the tooling, not
the process. The site is a logbook, not a portfolio of software.

## What this site is about

- Getting designs from **vision to paper as fast as possible**.
- All tools allowed. All help allowed. Vibe coding everything is fine.
- The end goal is **the design on paper** — not the code, not the tooling, not the process.
- Multiple designs are in flight at any given time. Designs are not expected to march
  linearly from "vision" to "finished".

## How to read this logbook

Every design has its own page with four sections, in order:

1. **Vision** — what I want this design to be / become.
2. **Inspiration** — references, links, images, prior art that fed into it.
3. **Journey** — a dated work log. Append-only. Dead ends, parameter sweeps,
   plotter mishaps, pen choices — the messy progress lives here.
4. **Status** — current state of the design (`vision` / `prototyping` / `plotted` / `shelved`).

A design page is **not** expected to progress linearly through these sections —
*Journey* and *Status* are living, while *Vision* and *Inspiration* are mostly written
up front.
